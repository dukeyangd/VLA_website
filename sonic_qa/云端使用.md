# skill_2 SONIC v1.1 回放 QA — 云端使用说明（cluster_0）

用于在 **cluster_0** 上对 unified 数据集做 **SONIC v1.1 latent GT 回放**，通过浏览器 **Viser** 目视检查动作质量，并输出 allow/deny 汇总。

- 物理：**Newton + Isaac Lab 3.0**（kit-less，非 PhysX）
- 策略：**SONIC v1.1**（磁盘 `z` → ATM.decode → 关节 PD）
- 可视化：**Viser 网页**（默认，无需 Isaac Sim GUI）

## 2. 快速开始

### 2.1 登录 cluster

```bash
ssh cluster_0
```

### 2.2 启动回放

```bash
cd /mnt/data2/wpy/workspace/Phi0_Dataset/Phi0-MixCorpus/datasets/830/skill2_sonic_qa

# 连续区间（例：60～70，共 11 条）
EPISODES=60-70 bash run_qa.sh
```

### 2.3 浏览器看机器人

在本机**另开一个终端**做端口转发（回放已在 cluster 上跑着）：

```bash
ssh -L 8081:127.0.0.1:8081 cluster_0
```

浏览器打开：**http://127.0.0.1:8081**

### 2.4 结束

在 **跑 `run_qa.sh` 的那个终端**输入 `q` 再回车 → 写出 summary 并退出。

## 3. 指定 episode

| 需求 | 命令 |
|------|------|
| 闭区间 | `EPISODES=60-70 bash run_qa.sh` |
| 不连续复查（第二轮 fail 列表） | `EPISODES="62 63 64 69" bash run_qa.sh` |
| 逗号写法 | `EPISODES=62,63,64,69 bash run_qa.sh` |
| 起止等价 | `EP_START=60 EP_END=70 bash run_qa.sh` |

**注意：** `EP_COUNT` 表示**条数**，不是结束编号。

- ✅ `EPISODES=60-70` → 60、61、…、70（11 条）
- ❌ `EP_START=60 EP_COUNT=70` → 从 60 起共 70 条（60～129）

并行环境数 = 所选 episode 数（自动，不固定 20）。

## 5. 输出说明

每批跑完后查看：

```
experiments/skill_2_pico_new826_unified_ep60-70/
├── batch_replay.log
├── batch_replay_summary.json   ← 主结果
├── allowlist.json
└── blacklist.json
```

`batch_replay_summary.json` 示例：

```json
{
  "ok": [60, 61, 62],
  "fail": [
    {"episode": 63, "reasons": ["sim_twitch"], "twitch": {...}}
  ],
  "n_ok": 3,
  "n_fail": 1
}
```

| reason | 含义 |
|--------|------|
| `fall` | 摔倒（高度/落差门限） |
| `sim_twitch` | 仿真关节抖动（多见，需结合画面） |
| `data_twitch` | 磁盘 teleop qpos 本身抖动（少见） |

**建议流程：**

1. 第一轮：按区间批量 QA（如 `0-19`, `20-39`, …）
2. 第二轮：把 `fail` 里的编号用不连续列表再跑一遍人工确认
3. 最终 allow/deny 以人工 + summary 为准

## 6. 常用环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `EPISODES` | 无则 `0-19` | 推荐：闭区间或不连续列表 |
| `LIVE_UI` | `1` | 开 Viser |
| `VISUALIZER` | `viser` | 网页；`kit`=Isaac GUI（慢，不推荐日常） |
| `VISER_PORT` | `8081` | Viser 网页端口（避开本机 Cursor 常用的 8080） |
| `LOOP` | `1` | 循环回放便于盯画面 |
| `LOOP_PAUSE` | `1` | 每轮间隔秒数 |
| `CUDA_VISIBLE_DEVICES` | `0` | 指定 GPU |

无界面快速自检（冒烟）：

```bash
EPISODES=0 LIVE_UI=0 LOOP=0 MAX_STEPS=100 bash run_qa.sh
```

云端 **Viser QA 不依赖 Isaac Sim pip 包**。已具备：

- Conda：`Phi-0-wbc-newton-wpy`

若 HuggingFace 下载 v1.1 失败（proxy 问题），需从已有机器 rsync 权重目录，或联系维护者。

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 8081 打不开 | 确认 `LIVE_UI=1`；本机已 `ssh -L 8081:...` |
| `No module named 'trl.experimental.ppo'` | 已修：同步最新 `newton_gate_common.py`；或 `pip install 'trl>=0.28.0'` |
| `No module named 'carb'` | 无害（Kit 键盘）；Viser 模式可忽略 |
| episode 数量不对 | 用 `EPISODES=起-止`，不要用 `EP_COUNT` 当结束编号 |
| 头顶编号太大 | 已调小；仍可调 `--ep_label_scale 0.5`（需改引擎参数） |
| 进程卡住 | `q`+回车 或 `Ctrl+C`；看 `experiments/*/batch_replay.log` |

```bash
cd .../skill2_sonic_qa
```
